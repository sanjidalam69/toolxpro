💾 Binary (JEDEC) vs Decimal (SI) File Math

Digital storage drives use decimal bytes (1 GB = 1,000 MB), whereas operating systems calculate binary GiB (1 GiB = 1,024 MiB). Our converter clearly breaks down both standards to explain disk capacity gaps.

Frequently Asked Questions (FAQ)

Q: Why does my hard drive show 931 GB instead of 1000 GB in Windows?

Manufacturers market drives using decimal 1,000 bytes per kilobyte, while Windows computes capacity using binary 1,024 bytes per kibibyte. 1,000,000,000,000 bytes ÷ (1024³) equals approximately 931.32 GiB. Our File Size Converter demonstrates this calculation directly.

Q: Does the QR Code Scanner require an internet connection?
